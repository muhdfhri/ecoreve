# ECOREVE DESIGN SYSTEM GUIDELINES

## 🎯 Core Design Standard: Option 3 (Natural Modern Curves)

This document establishes the official UI/UX design tokens and rules for the **EcoReve Industrial Water Systems** platform.

---

### 1. Border Radius Standards

| Element Category | Tailwind Class | Radius Value | Examples |
| :--- | :--- | :--- | :--- |
| **Main Containers & Cards** | `rounded-2xl` | `16px` | Product Cards, Filter Sidebars, Feature Bento Cards, Modal Boxes |
| **Hero & Major Banners** | `rounded-3xl` | `24px` | Top Hero Containers, Dark Section Banners |
| **Inputs & Buttons** | `rounded-xl` / `rounded-lg` | `12px` / `8px` | Search Form Inputs, Category Accordion Inputs, Action Buttons |
| **Floating Nav Bar** | `rounded-full` | `9999px` | Main Floating Navbar Pill |
| **Checkboxes** | `rounded` | `4px` | Filter Accordion Checkboxes |

---

### 2. Search Inputs & Outlines

- **Outline Style**: Natural, clean, high-contrast borders: `border-2 border-black/80 dark:border-white/80 focus:border-black dark:focus:border-white`.
- **Shadows**: Avoid heavy floating drop-shadows on inputs (`shadow-none`). Keep input fields clean and flat for intuitive UX.

---

### 3. Color Tokens

- **Primary Corporate Blue**: `#005883`
- **Secondary Accent Teal**: `#008193`
- **Accent Green**: `#8ec63f`
- **Background Base**: `#fafbfc` (Light) / `#0f1c24` (Dark)
