# ECOREVE DESIGN SYSTEM RULES (OPTION 3 - NATURAL MODERN CURVES)

All pages and components in this repository MUST strictly follow Option 3 Design System Rules for visual consistency:

1. **Card & Container Radius**:
   - Primary Cards, Modals, Banner Containers, & Sidebars MUST use `rounded-2xl` (16px) or max `rounded-3xl` (24px for major hero banners).
   - NEVER use exaggerated `rounded-[2.5rem]` / `rounded-[2rem]` (32px-40px) or rigid `rounded-none`.

2. **Input Forms & Buttons Radius**:
   - Form Inputs, Select Dropdowns, Action Buttons, & Interactive Cards MUST use `rounded-xl` (12px) or `rounded-lg` (8px).
   - Floating Navigation Bar uses standard `rounded-full`.

3. **Input Outlines & Borders**:
   - Search forms and text inputs MUST use clean, natural black border outlines (`border-2 border-black/80 dark:border-white/80 focus:border-black dark:focus:border-white`) without artificial heavy drop-shadows (`shadow-none` / natural flat layout).
